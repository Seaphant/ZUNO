# Deploy to Vercel for ZUNO URL

## Quick Deploy (2 minutes):

1. **Login to Vercel:**
   ```bash
   cd /Users/williamnguyen10/zuno-ui
   vercel login
   ```

2. **Deploy:**
   ```bash
   vercel --prod
   ```

3. **You'll get a URL like:**
   - `zuno-ui.vercel.app` (or similar with "zuno" in the name)
   - This will be permanent and accessible from anywhere!

## Alternative: Use Current Cloudflare Tunnel

The current tunnel URL is being generated. It will be random but accessible immediately.
